📌 Project Overview

This project is created as part of the Digital Literacy course to demonstrate essential digital skills required in today’s academic and professional environment. The project consists of five modules, each focusing on a key area of digital literacy. All tasks, resources, and reflections are organized in this repository.

📂 Module Summary

📊 Module 1: Digital Literacy Awareness

Created an infographic using Canva to explain digital literacy, safe internet practices, and useful tools for students. This helped in understanding how to present information visually.

---

🌐 Module 2: Student Digital Portfolio

Built professional profiles on platforms like GitHub, LinkedIn, and Kaggle. Learned how to maintain a digital identity and showcase skills for future opportunities.

---

💻 Module 3: Coding & Collaboration Platforms

Completed a beginner coding challenge on HackerRank and created a Google Form quiz. This module improved problem-solving skills and collaboration using online tools.

---

📧 Module 4: Email Etiquette & Communication

Drafted professional emails and created a social media checklist. Learned proper email structure, tone, and responsible online communication.

---

🔐 Module 5: Cybercrime Awareness

Studied cybercrime cases like phishing and online fraud. Created a prevention checklist to promote safe online practices among students.
